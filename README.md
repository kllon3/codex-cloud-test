# 飞机大战外星人

使用 Python 3 和自带的 Tkinter，所有飞机、外星人和爆炸效果都由代码绘制，不需要图片素材或第三方 Python 库。

在有图形桌面的电脑上运行：

```bash
python3 alien_shooter.py
```

Windows 也可以使用 `python alien_shooter.py`。
部分 Linux 发行版需要额外安装系统提供的 `python3-tk`。

| 按键 | 功能 |
| --- | --- |
| Enter | 开始游戏 / 游戏结束后重新开始 |
| 方向键 / WASD | 移动飞机 |
| 空格（可长按） | 射击 |
| P | 暂停 / 继续 |
| Esc | 退出 |

击落一个外星人获得 100 分。你有三条生命，受击后有短暂保护时间。
清空敌人后进入下一波，外星人的速度和射击频率逐渐提高。
生命耗尽，或外星人抵达屏幕底部，游戏结束。
窗口失去焦点时自动暂停，返回窗口后按 P 继续。
